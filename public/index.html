구병원 주차감면 시스템 안내

1. 시스템 개요

원내 주차 관제 서버(211.105.143.22)의 할인/감면 로직을 중계하여 스마트폰과 EMR 환경에서 초고속으로 감면을 적용하는 전용 모바일 웹입니다.

2. 주요 사용법

  • 차량번호 4자리 입력 시 입차 정보 자동 검색
  • [원클릭 감면] 버튼 터치 시 1초 만에 감면 적용
  • 부서 아이디는 기기별로 1회 저장 지원
  • 태블릿/터치 모니터는 [키패드 열기] 지원

3. 모바일 앱처럼 바탕화면에 추가

스마트폰 브라우저 메뉴 ➔ [홈 화면에 추가]를 누르시면 앱 아이콘처럼 설치되어 주소 입력 없이 1초 만에 실행됩니다.
